# Glowin · Visioncare — tienda en línea

Tienda estática para GitHub Pages con panel de administración en `/admin`
(misma estructura que la tienda Sweetie & Psycho).

- `data/store.json`: todo el contenido (productos, colecciones, colores, carrito, entregas y pagos).
- `assets/products/`: fotos de los lentes (tomadas del catálogo de Canva).
- `admin/`: panel para editar productos, colecciones, portada, colores y pedidos.

Entregas: Tegucigalpa L 70 · Nacional L 90. Pedidos al correo con Web3Forms
(botón "Agendar pedido") y números GLW-10001, 10002…
